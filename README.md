1. Create public repo `suhaasdev/github-snake`
2. Add `.github/workflows/snake.yml` from this folder (already set to `github_user_name: suhaasdev`)
3. Settings → Actions → General → **Read and write permissions** → Save
4. Actions → Generate Contribution Snake → Run workflow
5. Verify `output` branch has `github-snake.svg` + `github-snake-dark.svg`

Runs daily (`cron: "0 0 * * *"`), on push to `main`, + manual dispatch.
